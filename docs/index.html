SR-HazardMaker

Turn ground-motion data into a hazard layer the ShakeReady map can use. Your files are read on your own computer. Nothing is uploaded.

Made by E. Taciroglu, University of California, Los Angeles.

Also from the command line

The same conversions are available as a command-line tool and Python package, tested to produce the same layers as this page. See the guide.
